# 第1章 ツールの概要

## 1.1 VA Requestとは

VA Requestは、弁護士会から購入する職務上請求書の用紙に、手書きをせずに、字を正しい位置に刷るためのツールです。

画面に用紙の画像を表示し、その上で欄をクリックして字を入れます。印刷するときは字だけを、用紙の実際の大きさで刷ります。請求ごとに、用紙の画像と字を重ねた PDF を保存できるので、刷る前に弁護士に確かめてもらえます。

VA Requestは、VBAアセットの記事「職務上請求書の定型用紙に印字（エクセルVBA）」の Excel のサンプルを、独立したプログラム（実行ファイル）に作り直したものです。Excel 版で必要だった、セルの幅と高さでの位置合わせや、印刷のたびに背景の画像を消す仕掛け、マクロの許可は要りません。

## 1.2 できること・できないこと

**できること**

- A〜D の4つの様式（戸籍謄本等職務上請求書・住民票の写し等職務上請求書・戸籍謄本等請求書・住民票の写し等請求書）に字を入れる
- ○ で囲む（戸籍・除籍・原戸籍、元号など）、□ に ✓ を付ける
- 自分の用紙をスキャンした画像を読み込み、欄の位置を用紙に合わせる（用紙のロットが替わったときも合わせ直せます）
- 例文を登録して、選んで入れる（例文のファイルを事務所の共有フォルダに置けば、何人かで同じ例文を使えます）
- 弁護士の氏名・登録番号など、毎回同じ欄を、初めから入れておく（既定の値）
- 用紙の画像と字を重ねた PDF を保存し、開き直して直す・刷り直す
- 字だけを、用紙の実際の大きさで印刷する（プリンターごとのずれを mm で補えます）

**できないこと（していないこと）**

- インターネットにつながること。外部と通信しません
- 職務上請求書の実物の様式を配ること。様式は一般に公開されていないため、配布物には、記事と同じダミーの様式だけを入れています。お使いの用紙をスキャンして読み込んでください（3.1）
- 請求の内容を、PDF のほかに残すこと（1.3）
- Mac での印刷。印刷は Windows でだけできます

## 1.3 どの情報がどこに置かれるか

| 情報 | 置かれる場所 |
|---|---|
| 請求の内容（対象者の氏名など） | 利用者が保存した PDF と、印刷した用紙だけ。設定ファイルには書きません |
| 例文 | 例文のファイル「職務上請求書例文.json」（置き場所は［ファイル］→［オプション］で決めます。既定はこの PC の設定の場所） |
| 既定の値・用紙の画像・欄の位置・プリンターのずれ | この PC の設定（`%APPDATA%\VA Request`） |
| 外部 | 送りません |

例文と既定の値は、請求をまたいで残ります。**依頼者や請求の対象者の名前は、例文と既定の値に入れないでください。**

保存した PDF には、開き直すための情報（様式・欄の位置・入力した値）を、PDF の添付のファイルとして入れています。画面に見える字と同じ内容で、ほかの情報は入れていません。PDF の文書情報（作成者など）に、利用者の名前は入れません。

# 第2章 導入方法

## 2.1 配布物の構成

| ファイル・フォルダ | 内容 |
|---|---|
| `VA_Request.exe` | VA Request の実行ファイル |
| `マニュアル\` | この操作マニュアル（PDF） |
| `LICENSE` | VA Request のライセンス（MIT License） |
| `THIRD_PARTY_NOTICES.txt` | 使っている部品のライセンスの全文 |
| `README.md` | 配布物の説明 |
| `source\` | ソースコード（第8章） |

## 2.2 起動方法

`VA_Request.exe` をダブルクリックします。インストールは要りません。好きなフォルダに置いて使えます。

職場によっては、署名のない実行ファイルの起動を制限していることがあります。起動できないときは、管理者に確かめてください。

保存した PDF を `VA_Request.exe` の上にドラッグして離すと、その PDF を開いた状態で起動します。

## 2.3 動作環境

- Windows 10・11
- 印刷には、A4 の用紙を使えるプリンター

Mac では、`source\` のソースコードから動かせますが、動作は保証しません。印刷はできません。

## 2.4 設定ファイルとアンインストール

設定は `%APPDATA%\VA Request` に置きます（エクスプローラーのアドレス欄に `%APPDATA%\VA Request` と入れると開きます）。

| ファイル | 内容 |
|---|---|
| `settings.json` | 既定の値・欄の位置・プリンターのずれ・前に保存したフォルダ・例文の置き場所など |
| `images\` | 読み込んだ用紙の画像の写し |
| `職務上請求書例文.json` | 例文（置き場所を変えていないとき） |
| `errors.json` | 思わぬ誤りの記録（誤りの種類と場所だけ。3.9） |

使うのをやめるときは、`VA_Request.exe` と、このフォルダを消してください。

# 第3章 はじめに行うこと

初めて使うとき（と、用紙のロットが替わったとき）は、次の順に用意します。

## 3.1 用紙の画像を読み込む

1. 何も書いていない用紙を、スキャナーで読み取ります（PNG か JPEG。300 dpi 程度）。用紙の全体が入るように読み取ってください。
2. リボンの［様式］の欄で、読み込む様式（A用紙〜D用紙）を選びます。
3. ［用紙の画像］→［用紙の画像を読み込む…］で、読み取った画像を選びます。画像に解像度の記録がないときは、読み取ったときの解像度（dpi）を尋ねます。
4. 画面に画像が出たら、**用紙の左上の角（紙の端）**をクリックします。用紙の位置が決まります。

読み込んだ画像は、この PC の設定の場所に写して覚えます。ダミーの用紙に戻すときは、［用紙の画像］→［ダミーの用紙に戻す］を選びます。

## 3.2 欄の位置を合わせる

欄（点線の四角）が、読み込んだ用紙の欄に合っているかを見ます。ずれていれば、リボンの［欄の位置］を押して合わせます。

- 欄（オレンジの四角）をドラッグして動かします。
- Ctrl を押しながらクリックするか、空いた所からドラッグして囲むと、いくつも選んで、まとめて動かせます（列ごとずれているとき）。
- 矢印キーで 0.5mm、Shift を押しながら矢印キーで 0.1mm 動きます。
- 1つだけ選ぶと、右下の角をドラッグして大きさを変えられます。右の欄に、位置と大きさを mm の数で入れることもできます。
- ［選んだ欄を初めの位置に］［すべて初めの位置に］で、組み込みの位置（ダミーの用紙での位置）に戻せます。
- 終えるときは、［位置合わせを終える］を押します。合わせた位置は、すぐにこの PC に覚えます。

用紙は、ロットによって、列の位置や大きさが少しずつ違うことがあります。新しいロットの用紙を使い始めるときは、その用紙を読み込み直して、位置を合わせ直してください。

## 3.3 普通紙で刷って確かめる（プリンターのずれ）

プリンターには、用紙を送るときのずれや、印刷できない縁があり、画面どおりの位置に刷られないことがあります。最初に、普通紙で確かめてください。

1. 試しに字を入れて、［保存］で PDF を保存します。
2. 保存した PDF を、PDF を見るソフト（Edge・Acrobat Reader など）で開き、**実際の大きさ（拡大・縮小なし）**で普通紙に刷ります。用紙の画像と字が重なって刷られます。
3. 刷った紙を実物の用紙と重ね、光に透かして、欄の線がずれていないかを見ます。
4. ずれていれば、VA Request の［印刷］の画面の「このプリンターのずれ」に、ずれの mm を入れます。字が左に刷られるときは「右へ」を、上に刷られるときは「下へ」を増やします（負の数も使えます）。ずれはプリンターごとに覚えます。

字だけを普通紙に刷り、実物の用紙と重ねて確かめることもできます。

## 3.4 例文の保存場所を決める

例文は、A〜D の様式の分を1つのファイル「職務上請求書例文.json」にまとめて保存します。置き場所は、メニューの［ファイル］→［オプション…］で決めます。

- 既定は、この PC の設定の場所です。
- 事務所の共有フォルダ（OneDrive・SharePoint の同期フォルダを含む）を選ぶと、何人かで同じ例文を使えます。
- 新しい置き場所にまだファイルがなければ、今の例文を写すかを尋ねます。ファイルがあれば、それを使います。

## 3.5 既定の値を入れておく

弁護士会・弁護士の氏名・登録番号・電話番号など、毎回同じになる欄は、既定の値にしておくと、新しい請求の初めから入っています。

1. 欄をクリックして字を入れます。
2. リボンの［既定の値にする］を押します。

既定の値がある欄では、右の欄に「既定の値：（値）」と出ます。消すときは、欄を選んで［既定の値を消す］を押します。

# 第4章 請求を作る

## 4.1 画面

- 左：用紙の画像と、その上に刷る字を重ねて表示します（プレビュー）。字を入れる欄は点線の四角、選んでいる欄は青い四角、字が入りきらない欄は赤い四角で示します。
- 右：選んでいる欄の入力と、例文の一覧です。
- 上：リボン（第5章）。
- 下：様式・保存したかどうか・入りきらない欄などを示します。

## 4.2 欄の呼び名

VA Requestは、様式の欄の名前（項目名）を持っていません（様式が公開されていないため）。欄は、次の呼び名で示します。お使いの用紙の画像に刷ってある項目名を見ながら入れてください。

- 「日付欄」：請求の年月日
- 「宛名欄」：「長殿」の前（請求先）
- 「欄1」「欄2」…：表の左の列の欄を、上から数えたもの
- 「欄1-1」「欄1-2」…：左の列の1つの欄の右に、字を入れる所がいくつもあるとき

## 4.3 字を入れる

左の用紙の上で、字を入れたい欄をクリックすると、右に入力欄が出ます。

- **1行の字・数**：入れると、すぐに左の用紙に表示されます。Enter か Tab で次の欄へ移ります（Shift＋Tab で前の欄）。
- **何行かの字**：欄の幅で折り返して刷ります。Enter で改行します。Tab で次の欄へ移ります。
- **日付**：年・月・日を分けて入れます。［今日］で今日の日付が入ります（A用紙・B用紙の請求の年月日は「令和7」のように元号を付けて入れます。C用紙・D用紙は「平成」が刷ってあるので、数だけを入れます）。生年月日の元号は、用紙の上の M・T・S・H・R などをクリックして ○ を付けます。
- **囲み（○）**：用紙の上の語（戸籍・除籍・原戸籍など）をクリックすると ○ が付き、もう一度クリックすると外れます。
- **印（✓）**：用紙の上の □ をクリックすると ✓ が付き、もう一度クリックすると外れます。

字が欄に入りきらないときは、字を小さくし、それでも入らなければ字の幅を詰めます。それでも入らない欄は、赤い四角で示し、保存・印刷の前に知らせます。字は削らずにそのまま刷るので、欄からはみ出します。字を減らすか、欄の位置合わせで欄を広げてください。

## 4.4 例文を使う

例文を登録してある欄では、右の欄に例文の一覧が出ます。例文をダブルクリックするか、選んで［入れる］を押すと、入力欄の、いまの文字の位置に入ります。入れた後に書き足せます。

**例文を登録する**：欄を選んで、リボンの［例文の登録］を押します。

- 例文の一覧の中で、直接書いて直します。
- ［足す］で、一番下に空の例文を足します。
- ［上へ］［下へ］［消す］は、いま書いている例文に効きます。
- 空の例文は、［OK］を押したときに除きます。

何人かで同じ例文のファイルを使っているときに、登録の画面を開いている間にほかの人が例文を変えると、知らせます。そのときに書くのは、自分が登録した欄の例文だけで、ほかの欄はほかの人が変えたまま残ります。

## 4.5 保存する

リボンの［保存］（または［ファイル］→［保存］、Ctrl+S）で、用紙の画像と字を重ねた PDF を保存します。印刷の前にも保存できるので、刷る前に弁護士に確かめてもらえます。

- 初めて保存するときだけ、保存の場所とファイルの名前を尋ねます（既定の名前は「職務上請求書_年月日.pdf」）。依頼者の名前などをファイルの名前に入れるかは、事務所の決まりに従ってください。
- 2回目からは、同じファイルに上書きします。

## 4.6 印刷する

用紙をプリンターに入れて、リボンの［印刷］（Ctrl+P）を押します。

- まだ保存していないか、保存した後に字を変えていれば、先に PDF を保存します（刷ったのに記録がない、ということをなくすため）。
- 印刷の画面で、プリンターを選びます。給紙の方法（手差しなど）は［プロパティ］で選びます。
- 「このプリンターのずれ」は、3.3 で確かめた値です。
- 字だけを、A4 の実際の大きさで刷ります。用紙の画像は刷りません。

## 4.7 保存した PDF を開いて直す・刷り直す

［開く］（Ctrl+O）で、VA Request で保存した PDF を開くと、保存したときの状態に戻ります。字を直したり、刷り損じたときに刷り直したりできます。

- 直した後の保存は、開いた PDF への上書きだけです（別の名前では保存できません）。前の請求を書き替えて別の請求に使い回さないでください。
- 開いた PDF の欄の位置と用紙の画像は、保存したときのものです。開いている間は、［欄の位置］と［用紙の画像］は使えません。
- 保存した後に欄の位置を合わせ直していれば、印刷の前に、今の位置で刷るか、保存したときの位置で刷るかを尋ねます。
- VA Request で保存したものでない PDF は開けません。

新しい請求を始めるときは、［新しい請求］（Ctrl+N）を押します。いつも空の状態から始まります（既定の値だけが入ります）。

# 第6章 困ったとき

## 6.1 よくある知らせと対処

| 知らせ | 対処 |
|---|---|
| 例文のファイルを読めません | 例文の保存場所（共有フォルダ）につながっているかを確かめてください |
| PDF を書き込めませんでした | ほかのソフトでその PDF を開いていれば、閉じてから保存し直してください |
| この PDF は開けません | VA Request で保存した PDF だけを開けます |
| 字を小さくしても欄に入りきりません | 字を減らすか、［欄の位置］で欄を広げてください |
| 使えるプリンターがありません | Windows の［設定］でプリンターを追加してください |

## 6.2 診断情報

不具合を相談するときは、メニューの［ヘルプ］→［診断情報をコピー］を押し、貼り付けて伝えてください。診断情報には、版・OS・様式・欄の数・入力した欄の数・誤りの種類と場所などだけが入ります。**欄の値（請求の内容）・例文・ファイルの名前と場所は入りません。**

# 第7章 AI を使ってツールを改造するとき

VA Request はソースコードを公開しており（第8章）、事務所独自の機能を、AI（プログラムを書くのを手伝う AI）を使って足すこともできます。その場合は、次の手順で、**AI が実データ（依頼者・請求の情報）に届かない場所で作業させてください。**

## 7.1 なぜ注意が必要か

AI が読んだファイルや画面は、AI の会社のサーバーに送られます。依頼者の情報を AI に読ませると、守秘義務の点で問題になり得ます。AI は作業の途中で、思わぬファイルを開くことがあります。そのため、「気をつけて使う」だけでは防げません。AI が実データに届かない場所で作業させてください。

## 7.2 手順1　AI 専用の Windows ユーザーを作る

- ［設定］→［アカウント］→［他のユーザー］で、AI の作業に使うユーザーを作ります。管理者にはせず、標準ユーザーにします。
- このユーザーでは、事務所の OneDrive・SharePoint にサインインしません。共有フォルダ・ネットワークドライブ・暗号化した仮想ドライブにもつなぎません。
- 作ったら、このユーザーでエクスプローラーを開き、事務所の共有データの場所が見えないこと、開けないことを確かめます。見える場合は、そのフォルダのアクセス許可からこのユーザーを外してください。
- 別の PC を AI の作業に使えるなら、さらに確実です。

## 7.3 手順2　このユーザーで、ソースと試用データだけを使って作業する

- ソースは、このユーザーで新しく手に入れます。サイトから配布物（zip）をダウンロードし直し、`source` フォルダのソースコードを使います（GitHub から取ってもかまいません）。ふだんのユーザーのフォルダから写さないでください。
- 試すときは、架空の字（実在の人の名前・本籍・住所などを使わない字）と、配布物に入っているダミーの様式を使います。保存した請求の PDF は使わないでください。
- 設定ファイル（`%APPDATA%\VA Request`）は、このユーザーで VA Request を起動して新しく作られたものを使います。ふだんの設定ファイルと例文のファイルを写さないでください（既定の値や例文に、名前が入っていることがあります）。
- 実データの中身を、AI に貼り付けたり、画面の写しで見せたりしないでください。
- 不具合を AI に相談するときは、［ヘルプ］→［診断情報をコピー］（6.2）を使います。

## 7.4 手順3　実データでの確認と入れ替えは、ふだんのユーザーで人が行う

- 改造してできた VA Request（ソースから動かすもの、または作り直した実行ファイル）を、ふだんのユーザーに移します。
- 設定の場所（`%APPDATA%\VA Request`）と例文のファイルのバックアップを取ってから、まず普通紙で試します。問題がなければ、使い始めます。
