# VA Request

弁護士会から購入する職務上請求書の用紙に、手書きをせずに、字を正しい位置に刷るためのツールです（Windows 用）。

- 画面に用紙の画像を表示し、その上で欄をクリックして字を入れます。
- 印刷するときは、字だけを、用紙の実際の大きさで刷ります。プリンターごとのずれを mm で補えます。
- 請求ごとに、用紙の画像と字を重ねた PDF を保存できます（刷る前に、弁護士に確かめてもらえます）。保存した PDF は、開き直して直せます。
- 自分の用紙をスキャンした画像を読み込み、欄の位置を用紙に合わせられます（用紙のロットが替わったときも合わせ直せます）。
- 例文を登録して選んで入れられます。例文のファイルを事務所の共有フォルダに置けば、何人かで同じ例文を使えます。
- 外部と通信しません。請求の内容は、保存した PDF と印刷した用紙のほかには残しません。

職務上請求書の様式は一般に公開されていないため、配布物にはダミーの様式（A〜D）だけを入れています。お使いの用紙をスキャンして読み込んでください。

## 使い方

`VA_Request.exe` をダブルクリックします。詳しくは、`マニュアル\` の操作マニュアルをご覧ください。

## ソースから動かす

```
pip install -r requirements.txt
python main.py
```

試験：`python -m pytest`
